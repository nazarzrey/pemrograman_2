## Langkah setelah JDK 8 terpasang

1. Buka project `latihan2` melalui `File > Open Project` di NetBeans 8.2.
2. Pilih JDK 8 pada `Tools > Java Platforms` atau pengaturan project.
3. Jalankan `Clean and Build Project`.
4. Jalankan project dan uji alur berikut:
   - isi nama lalu klik `Tampilkan`;
   - kosongkan nama lalu klik `Tampilkan` untuk melihat pesan informasi;
   - klik `Bersihkan` untuk mengembalikan form ke kondisi awal.
